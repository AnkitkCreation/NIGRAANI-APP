# NIGRANI Product Roadmap 🚀

This document tracks all implemented features, suggested ideas, and the path to making NIGRANI a market-ready civic platform.

## ✅ Implemented Features
- **Multi-Language Support**: English, Hindi, Marathi.
- **Civic Reporting Flow**: Multi-step reporting with GPS and Photo capture.
- **"Me Too" (Upvoting)**: Collective impact system for issue prioritization.
- **Modern Dashboard**: High-level city overview and personal stats.
- **Dynamic Map**: Real-time visualization of reports across Pune.
- **Notification Center**: Fully localized hub for real-time civic updates.
- **Transparency Portal**: Visibility into government budgets and contractor performance.

## 📋 Ongoing Work
- **Gamification Engine**: Developing the "Impact Score" and user levels system.

## 🚀 Future Roadmap (Market Ready Features)

### Phase 1: Power Up (AI & Data)
- [ ] **AI-Powered Validation**: Use Gemini Vision to automatically verify photos and categorize issues.
- [ ] **Objective Severity Scaling**: AI-driven analysis of how "Critical" an issue is based on visual evidence.
- [ ] **Notification Center Enhancements**: Mark all as read, delete notifications, and push notification mock-ups.

### Phase 2: Administrative Excellence
- [ ] **Contractor Portal**: A separate UI for field workers to claim tasks and upload "After" photos.
- [ ] **Transparency Dashboard**: Public rankings of contractors and real-time budget utilization data.
- [ ] **Ward-wise Analytics**: Performance reports for citizens and government officials.

### Phase 3: Community & Scale
- [ ] **Citizens' Discussion Feed**: Allow comments on public reports to provide more context.
- [ ] **Gamification (Impact Score)**: Badges and titles like "Civic Guardian" for active users.
- [ ] **Offline PWA Support**: File reports without internet; auto-sync when back online.

### Phase 4: Production Ready
- [ ] **Database Integration**: Migrate from mock data to Supabase/Firebase.
- [ ] **User Auth**: Real Mobile OTP login flow.
- [ ] **Production Monitoring**: Error tracking and performance optimization.
